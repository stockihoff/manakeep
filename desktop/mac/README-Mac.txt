MANAKEEP ON A MAC
=================

Install
  1. Unzip "Manakeep for Mac.zip".
  2. Right-click "Install Manakeep.command" and choose Open, then Open again.
     (macOS asks because it isn't from the App Store. This only happens once.)
  3. Manakeep is copied into Applications and opens. Drag it to your Dock.

Update
  Get the new version and run "Install Manakeep.command" again.
  The old version is removed and replaced. Your collection and decks are kept.

Remove
  Drag Manakeep from Applications to the Bin. Your collection and decks are kept.

You need Google Chrome or Microsoft Edge installed. They are the browsers that
can save straight into a folder.

If macOS says something "is damaged" (this can happen after downloading),
open Terminal and run:
    xattr -dr com.apple.quarantine ~/Downloads/Manakeep\ for\ Mac
then try again (change the path to wherever you unzipped it).
